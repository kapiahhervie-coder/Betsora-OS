Betsora Quiz Game Builder

Buat kuis kustom, atur tingkat kesulitan, dan ekspor/impor JSON untuk digunakan di Betsora OS.

Format berkas JSON untuk Impor (klik untuk melihat)

Simpan teks berikut sebagai berkas berakhiran .json (Notepad → Save As → ketik kuis.json, Encoding UTF-8), lalu klik Impor JSON.

{
  "judul": "Ulangan Harian Perkalian",
  "soal": [
    {
      "q": "Berapakah 12 x 8?",
      "a": ["86", "96", "106", "98"],
      "correct": 1,
      "hint": "Perkalian di bawah 100"
    }
  ]
}
  • a wajib tepat 4 pilihan. correct berupa angka 0–3 (0=A, 1=B, 2=C, 3=D); huruf "A"–"D" juga diterima.
  • hint boleh dikosongkan. Maksimum 100 soal.
  • Daftar soal polos [ {...}, {...} ] juga bisa diimpor.

Arsitektur Integration Spec - Betsora OS

Cetak biru API, Skema Database, dan WebSocket Payloads untuk integrasi Laravel / Node.js Backend.

1. WebSocket Live Battle Events (Socket.io) Real-time Protocol 

// Client -> Server: Submit Answer
socket.emit('submit_answer', {
  room_code: 'BET-9824',
  participant_id: 'usr_8812',
  question_id: 104,
  selected_option: 1, // Index B
  response_time_ms: 1850
});

// Server -> Client: Broadcast Realtime Score
socket.on('score_update', (data) => {
  // data: { score: 1250, streak: 3, leaderboard: [...] }
  updateLeaderboardUI(data.leaderboard);
});

2. Database Schema Blueprint (MySQL / PostgreSQL) Relational Tables 

TABLE quizzes (
  id INT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(255),
  mode ENUM('millionaire', 'kahoot_battle'),
  safe_checkpoints JSON, -- [5, 10]
  created_by INT
);

TABLE questions (
  id INT PRIMARY KEY AUTO_INCREMENT,
  quiz_id INT FOREIGN KEY,
  question_text TEXT,
  options JSON, -- ["A", "B", "C", "D"]
  correct_option INT,
  hint_text TEXT
);
